# Abhishek Sharma — Portfolio Film

## Treatment

- **Format and runtime:** 16:9 landscape, 28 seconds, five scenes.
- **Promise:** Abhishek builds useful software and thinks in systems.
- **Identity:** The portfolio's near-black, off-white, and restrained sage palette; editorial display typography; compact monospace labels; hairline rules and measured grid marks.
- **Hero:** A terminal cursor that becomes a project index, then a document/workspace interface.
- **Motion:** Stiff typographic snaps, deliberate camera-scale transitions, and object-led line/plane transformations. No particles, glow, or ornamental effects.
- **Arc:** Quiet boot → emphatic thesis and project archive → detailed AssetGuard interface → GitDocs document/branch system → palette-inverted invitation and seamless return to boot.
- **Payoff:** The closing sheet folds into the opening terminal cursor, so the last frame and first frame share a dark field, sage caret, and upper-left anchor.
- **Sound:** One restrained instrumental electronic bed, no voiceover or sound effects. Target 96–104 BPM with a warm, minimal pulse. Beat placement remains unverified until the generated track is heard against the cut.

## Pre-code review

- **Distinct framing:** Boot terminal plane; asymmetrical thesis/archive split; nearly full-frame asset-tracking workspace; top-down page/branch map; palette-inverted oversized type. Adjacent shots change layout, medium, and scale.
- **Motion variety:** Discrete terminal snaps; rule-to-index transformation; scale-through and folding archive; layered workspace unrolling; line-to-branch continuity; page map pull-back; paper-fold end transition.
- **Beat density:** The opening changes every 0.4–0.6s. Later scenes have a named action or content change at least once each second, with no empty incoming image.
- **Readable hierarchy:** One main action at a time; project content is set as a real label and concise technology rail. Main copy is 7–10vmin with 2.0–3.5vmin supporting labels. Technical lines remain secondary.
- **Factual restraint:** Names, role, project names, GitDocs frontend status, project functions, technology labels, and contact identifiers are limited to the supplied portfolio/resume/repository context. No user counts, monetary values, launch results, dates, client names, test scores, or invented history are displayed.
- **Finale:** Distinct palette, scale, and typographic composition; contact content is visible; final fold is active and returns to the first caret anchor.
